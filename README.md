Pokémon Generation I Save File Parser (MVP)

A python script which reads a Pokemon Gen 1's save file and returns the player's:
- Name
- Rival's name
- Amount of money
- List of badges
- List of pokemon in your party with their species and level

Support save files from Pokemon Red/Blue(US/EU)

Output Example:
Player: Jimmy
Rival:  GARY
Money:  2245 ₽
Badges: None
Party (2 Pokémon):
  1. Squirtle (Level 10)
  2. Weedle (Level 3)
