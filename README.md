v.0.1.0 Pokémon Generation I Save File Parser (MVP)

A python script which reads a Pokemon Gen 1's save file and returns the player's:
- Name
- Rival's name
- Amount of money
- List of badges
- List of pokemon in your party with their species and level

Support save files from Pokemon Red/Blue(US/EU)

Output Example:
Player: Jimmy
Rival:  GARY
Money:  2245 ₽
Badges: None
Party (2 Pokémon):
  1. Squirtle (Level 10)
  2. Weedle (Level 3)

v.0.1.1

A python script which reads a Pokemon Gen 1's save file and returns the player's:
- Name
- Rival's name
- Amount of money
- List of badges
- List of pokemon in your party with their species and level
- List of items in your bag
- List of items in your pc

Support save files from Pokemon Red/Blue(US/EU)

Player: Jimmy
Rival:  GARY
Money:  2245 ₽
Badges: None
Party (2 Pokémon):
  1. Squirtle (Level 10)
  2. Weedle (Level 3)
Bag items (2 slots):
  Town Map x1
  Poké Ball x4
PC items (1 slots):
  Potion x1
